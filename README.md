Objective

The objective of this project is to develop foundational network traffic analysis skills through hands-on exercises in the TryHackMe SOC Level 1 learning pathway. The project focuses on using Wireshark to capture, filter, and analyze network packets to better understand network protocols, communication patterns, and potentially suspicious activity.

Through guided exercises and practical investigations, I will document my learning progress, analyze packet captures (PCAPs), practice identifying relevant network indicators, and develop a stronger understanding of how security analysts use network traffic to investigate potential security incidents. NetworkMiner will also be used in selected exercises to explore network evidence and extract relevant artifacts.

This repository will serve as a technical learning portfolio documenting my progress in network traffic analysis and its application to Security Operations Center (SOC) investigations.
Skills Learned

    Understanding the fundamentals of network traffic analysis and packet inspection.

    Navigating Wireshark and interpreting packet details.

    Using Wireshark display filters to isolate relevant network traffic.

    Understanding common network protocols and their communication patterns.

    Examining packet headers, source and destination IP addresses, ports, and protocol information.

    Analyzing DNS, HTTP, TCP, and other protocols as covered in the exercises.

    Inspecting PCAP files to investigate network activity.

    Recognizing potentially suspicious traffic patterns and indicators that warrant further investigation.

    Using NetworkMiner to explore network evidence and extract artifacts where appropriate.

    Documenting investigation findings and explaining the evidence supporting conclusions.

Tools Used

    Wireshark – Primary tool for packet capture analysis, protocol inspection, filtering, and network troubleshooting.

    NetworkMiner – Supplementary network forensic analysis tool used to inspect packet captures and identify or extract relevant network artifacts.

    TryHackMe SOC Level 1 – Guided learning pathway providing network traffic analysis exercises and practical investigation scenarios.

    PCAP files – Packet capture files used to practice inspecting and analyzing network communications.
